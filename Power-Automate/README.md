# Aprovação de solicitação com Power Automate

Eu desenho um fluxo para aprovar uma solicitação de compra: detectar um novo item, validar os campos, aguardar uma aprovação, atualizar o estado e notificar o solicitante. Também registro erros de integração para acompanhamento.

Este README documenta o fluxo e as condições. Ele não é uma exportação de uma instância Power Automate.
