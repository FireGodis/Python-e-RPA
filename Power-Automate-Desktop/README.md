# Conferência de planilha com Power Automate Desktop

Neste exercício eu organizo uma automação desktop que lê um CSV, valida campos obrigatórios, separa linhas válidas de inconsistências e grava um resumo com horário e quantidade processada.

Eu mantenho a validação separada da interação visual para facilitar a manutenção. O fluxo visual deve ser montado no Power Automate Desktop; este README descreve a sequência e os pontos de conferência.
