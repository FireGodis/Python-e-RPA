# Cliente configurável para serviço LLM

Eu preparei um cliente Python para enviar uma solicitação a um endpoint compatível com chat completions. URL e credencial vêm de variáveis de ambiente, evitando gravar segredos no código.

Defina `LLM_BASE_URL` e `LLM_API_KEY` localmente antes de executar. Não incluí credenciais e o cliente não é executado automaticamente.
